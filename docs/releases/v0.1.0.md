# ManuscriptLint v0.1.0

The first public alpha release of **ManuscriptLint — ESLint for academic manuscripts**.

ManuscriptLint is the project-level preflight tool in the Academic Lint family. FigureLint checks exported figures, RefLint checks bibliographic data, and ManuscriptLint checks how a LaTeX submission project fits together.

## Highlights

- duplicate LaTeX label detection
- unresolved `\\ref{}` / `\\eqref{}` detection
- missing BibTeX citation-key detection
- missing included source / bibliography / figure files
- figure and table caption checks
- TODO / FIXME detection
- entry-point-aware LaTeX include graph
- include-cycle detection
- informational unused figure diagnostics
- informational unused BibTeX entry diagnostics
- `\\nocite{*}` handling
- optional FigureLint and RefLint orchestration
- machine-readable JSON output
- native GitHub Actions annotations
- reusable composite GitHub Action
- Python 3.10–3.12 support

## Quick start

~~~bash
pip install manuscriptlint
manuscriptlint check paper/
~~~

Strict CI behavior:

~~~bash
manuscriptlint check paper/ --strict
~~~

Machine-readable output:

~~~bash
manuscriptlint check paper/ --format json
~~~

Full Academic Lint preflight when FigureLint and RefLint are installed:

~~~bash
manuscriptlint check paper/ --figurelint --reflint
~~~

## GitHub Actions

~~~yaml
- uses: coocoomaomao/ManuscriptLint@v0.1.0
  with:
    path: paper/
    strict: "true"
~~~

## Status

v0.1.0 is an alpha release focused on deterministic LaTeX project checks. It does not assess scientific quality, novelty, acceptance likelihood, or guarantee publisher compliance.
